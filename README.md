# DNS Manager

Клиент-серверное приложение для управления DNS-серверами на удалённой машине через `/etc/resolv.conf`.

## Особенности реализации

**Конфигурация через переменные окружения**
Все важные параметры (порт сервера, путь к файлу, адрес сервера) вынесены в переменные окружения.

**Безопасный конкурентный доступ к файлу**
При одновременных запросах к серверу доступ к `/etc/resolv.conf` защищён мьютексом ( Избегаем гонки данных ).

**Graceful Shutdown**
Сервер отлавливает сигналы `SIGINT` и `SIGTERM` при остановке докручивает уже пришедшие запросы, после чего завершается ( таймаут - 5 секунд).

**Логирование**
Все ошибки и события логируются с временными метками — упрощает диагностику проблем в production.

## Требования

- Go 1.22+

## Сборка

```bash
# собрать сервер
go build -o dns-server ./cmd/server

# собрать клиент
go build -o dns-client ./cmd/client
```

## Запуск

### Сервер

```bash
# по умолчанию использует /etc/resolv.conf, порт 8080
sudo ./dns-server

# с указанием пути до файла и порта для запуска
RESOLV_CONF_PATH=/tmp/resolv.conf SERVER_ADDR=:8080 ./dns-server
```

Переменные окружения:
`SERVER_ADDR` - порт сервера ( по умолчанию `:8080`) 
`RESOLV_CONF_PATH` - путь к файлу ( по умолчанию `/etc/resolv.conf` )

### Клиент

```bash
# по умолчанию подключается к localhost:8080
./dns-client list

# с указанием адреса сервера
SERVER_URL=http://192.168.1.1:8080 ./dns-client list
```

Переменные окружения:
`SERVER_URL` - адрес сервера ( по умолчанию `http://localhost:8080`)

## Команды клиента

```bash
# список всех DNS серверов
./dns-client list

# добавить DNS сервер
./dns-client add 8.8.8.8

# удалить DNS сервер
./dns-client remove 8.8.8.8

# справка
./dns-client --help
```
